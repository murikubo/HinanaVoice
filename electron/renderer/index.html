Vocoflex 자동 설정

평소 쓰는 Vocoflex 자체를 참고 목소리에 맞춥니다.

8초 발성 분석 → 히나나 음색·피치를 Vocoflex에 저장 → Vocoflex 재실행

마이크 입력은 헤드폰 사용을 권장합니다. 가상 케이블은 다른 앱의 출력을 해당 케이블로 보내세요. 처음 8초 동안 평소 목소리로 말하거나 입력을 재생해 주세요.

시작 버튼을 누르면 입력을 받습니다.

Vocoflex 자체 설정 모드는 기존 설정을 백업하고 Vocoflex를 재실행합니다. 적용 후에는 Hinana Voice를 닫아도 Vocoflex에서 평소처럼 말하면 변환됩니다. 화자가 바뀌면 다시 분석하세요. 말투·억양은 입력을 따릅니다.
